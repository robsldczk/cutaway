Standard license texts, for packages that name their license without including its text
(`scripts/licenses.mjs`). `<copyright holders>` is replaced with the package's authors.

Taken from packages that ship them: MIT and Apache-2.0 from `serde`, BSD-3-Clause from
`alloc-no-stdlib`, MPL-2.0 from `cssparser`. ISC is the text published by the OSI. CC-BY-4.0 points
at the license, which the license itself allows (section 3(a)(1)(C)).
