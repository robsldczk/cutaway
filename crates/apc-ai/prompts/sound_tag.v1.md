# Task: tag a sound file

From the file name, its duration and (if given) the cue it was imported for, pick one library category (`SFX/Doors`, `SFX/Alarms`, `SFX/Machines`, `SFX/Foley`, `SFX/Impacts`, `SFX/Phones`, `SFX/Vehicles`, `SFX/Animals`, `SFX/Misc`, `Ambience`, `Music`) and a few short lowercase tags.
