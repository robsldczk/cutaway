# Task: condense director notes

For each take you get the room speech before it (direction) and after it (feedback). Condense each into **a few words** an editor can scan, written as instructions or reactions, not transcript fragments:

- direction examples: "quieter, to yourself", "more oomph on 'science'", "annoyed"
- feedback examples: "liked it", "the pick", "too fast", "technical problem"

Use an empty string when there is nothing relevant. Add short lowercase tags (e.g. `quieter`, `louder`, `energy`, `emphasis`, `annoyed`, `excited`, `re-take`, `technical`, `flub`, `ad-lib`, `pick`, `liked`). Never invent notes that aren't in the text.
